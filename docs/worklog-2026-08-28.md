## 1. Project inspection — "how many business days?"
- The app (**horasExtras**) is a Brazilian overtime-pay calculator
  (React + TypeScript + Vite, deployed via Cloudflare Workers/Wrangler).
- It does **not** model business days. The base hourly rate uses a fixed
  monthly-hours divisor: `HORAS_MENSAIS = 200` in `src/config.ts`.
- Base hourly rate = `salary / horasMensais` (`src/utils/calculations.ts`),
  each band applies a multiplier (1.5×, 1.75×, 2×, night adicionais,
  sobreaviso 1/3, etc.).

## 2. DSR feature (Súmula 172 TST) — SHIPPED
- Formula: `DSR = total de HE × (dias de DSR / dias úteis)`, where
  dias de DSR = domingos + feriados, dias úteis = dias do mês − dias de DSR.
- Decision: use a **fixed ~22% estimate** applied to **all bands except the
  base hour** ("Valor Hora Normal").
- Implemented:
  - `DSR_RATE = 0.22` in `src/config.ts`.
  - `calculateDSR(totalHE, rate)` pure fn in `src/utils/calculations.ts`.
  - `HoursCalculator.tsx`: sums overtime bands (category !== 'base') and
    shows Total / DSR estimado (~22% das HE) / Total com DSR.
  - Tests added in `src/utils/calculations.test.ts`.
- **Committed & pushed** as `751f960 "Add DSR"` on `origin/master`.
